# AgentMesh Studio

CLI tools and dashboards for monitoring and managing the AgentMesh.

## Features

- **Mesh Monitoring**: Inspect active agents and messages.
- **Project Management**: Initialize and manage AgentMesh projects.
- **Diagnostics**: Health checks for relays and vault connections.

## Usage

```bash
uv run agentmesh-studio monitor
```

## Structure

- `agentmesh.studio.main`: CLI entry point using `Typer`.
